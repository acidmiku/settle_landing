# Settle Landing — Design Guidelines

## Design Context

### Product
Settle is a local desktop editor for Windows and macOS: notes, code snippets, and Markdown. The editor fills the window, tabs hold unfinished thoughts, `Esc` hides it and a global shortcut (`Ctrl/Cmd+Shift+Space`) brings it back from any app. Ten selectable designs; Scratch (graphite + pink) is the default. Everything stays on the device.

### Users
Power users who choose tools deliberately. Keyboard-first, protective of their attention, allergic to oversold software marketing and generic AI-made aesthetics. They want to understand Settle in seconds, see the real thing, and either download or leave.

### Brand Personality
**Quiet but bold. Invisible but always present.** Like the app itself: gone on `Esc`, back on a keystroke. Plain language, short sentences, no exclamation marks, no growth-team voice. The app's own words are the best copy ("Let it out. Start anywhere.", "Ten ways to settle in.").

### Aesthetic Direction
**The page wears Settle.**

- The page is skinned with the app's ten designs. Scratch is the default; visitors can switch the whole page to any design (header switcher, the in-window gear, or "Use on this page" in the designs stage). The choice persists per browser.
- Each design brings its palette **and** its typographic posture: one variable family (Archivo, width + weight axes) and one variable mono (Martian Mono) are bent per design — condensed and heavy for Kiln, light and spacious for Blackbox, mono for Optic/Phosphor/Tape, expanded for Cobalt, 900-weight for Redline. Weight/width morph smoothly between designs.
- Strong, solid color accents from the design's own palette. Never gradients, never gradient text.
- Show the real app: the editor window is a live, faithful HTML replica of Settle's chrome (same tokens, same layout rules, same libraries — highlight.js, Marked, DOMPurify — vendored from the app).
- Quiet = few words, generous space, no decoration that doesn't come from the app. Bold = huge type, full-bleed color floods, solid accent CTAs.

### Motion
Motion is welcome and intentionally not gated by `prefers-reduced-motion` (owner's call).
- Load: masked line rises on the headline, then the window rises and types its own note.
- Hide/summon: the window's real behavior — `Esc` hides with a quick ease-in, the shortcut (or the floating chip) brings it back with an ease-out-expo, as a floating window if you've scrolled away.
- Designs stage: pinned, scroll-driven, deliberately short — Scratch, Kiln, Blackbox, then "And seven more": the other seven as slabs (spines) wearing their own palette and type, opening on hover/focus, taking turns when idle, and wearing the page on click. Each step wipes in vertically in the scroll direction with slight parallax. Nobody scrolls through ten full steps.
- Design switch: view-transition circle reveal from the click point; registered custom properties crossfade colors and morph font weight/width.
- Keyboard section: pressing a shortcut floods its row with the accent.
- Easing: exponential ease-outs (`cubic-bezier(.16,1,.3,1)`), no bounce or elastic.

### Constraints
- GitHub Pages: static files only, no build step, relative paths, `.nojekyll`, `CNAME` kept.
- Release info comes from the GitHub REST API client-side (cached, rate-limit friendly), with static links to `/releases/latest` as the fallback. Only versions ≥ 0.2.0 are offered — 0.1.0 is the old pre-rebuild app.
- No claims the app doesn't make (no "open source license", no telemetry claims). Mirror the README.

### Principles
1. **The app is the hero.** Every visual idea comes from Settle itself — its designs, its shortcuts, its hide/summon loop.
2. **Quiet until touched.** Few elements at rest; interaction and scrolling reveal the boldness.
3. **One accent per design, used with conviction.** Headline, CTAs, caret, active keys.
4. **Keyboard-first page.** Shortcuts work on the page; focus rings are real; everything is reachable without a mouse.
5. **Every design must be legible.** Each skin is checked for AA contrast on body text; small accent text uses `--p-hi` where the raw accent is too light.
