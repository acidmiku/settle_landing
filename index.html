Hands stay on the keys.

Every action has a shortcut. Press one.

  1. CtrlS Save New drafts go to your dated notes and the tab clears for the next thought. Saved notes update in place.
  2. CtrlEnter Copy + clear The text goes to the clipboard and the tab empties. If copying fails, your text stays put.
  3. CtrlN New tab Every tab is a draft. Close Settle mid-sentence; text, syntax and preview state come back with it.
  4. CtrlF Find Find in the current tab. F3 and ShiftF3 step through the matches.
  5. CtrlK Search notes Search every saved note from anywhere in the editor.
  6. CtrlShiftH Saved notes A drawer of everything you've saved, grouped by day.
  7. Ctrl, Settings Designs, word wrap, Enter to save, the global shortcut, startup, updates and your data.
  8. Esc Hide Dismisses a menu, the find bar or the drawer. Otherwise, Settle steps out of the way.
  9. CtrlShiftSpace Come back From any app. Change the shortcut or turn it off in Settings, or let Settle open when you sign in.

Plain text, until it isn't.

Syntax, detected

Auto mode recognises the language on your device as you type. Pick one yourself, or choose Plain text to turn highlighting off. Each tab remembers.

JavaScript TypeScript JSON HTML/XML CSS Python Rust PowerShell Bash SQL YAML INI/TOML C C++ C# Java Kotlin Swift Go Markdown and more in the selector

Markdown, previewed

Headings, lists, tables, task checkboxes and highlighted code render in place of the editor. Preview never changes your text.

Web and email links open in your default apps. Remote images show their alt text, and scripts are removed.

Lines, wrapped and counted

Word wrap fits long lines to the window in every design and syntax. Turn it off in Settings → Writing to scroll sideways instead. Your text never gains line breaks it didn't have.

Line numbers in every design, one per logical line however the text wraps.

Right-click a tab to close it, or close everything, with or without saving.

Builds are on GitHub Releases.

Settle updates itself from 0.2.1 on: Settings → Updates checks the latest release, verifies its signature and restarts with your drafts saved. Coming from 0.2.0, install 0.2.1 by hand once.

The macOS build isn't notarized yet. Copy Settle into Applications first, then allow it under System Settings → Privacy & Security the first time you open it.

Built with Rust and Tauri 2. The source is on GitHub.
