A notes app for Windows

Instant capture.
Quiet recall.

Settle is a keyboard-first notes app. Append to a day note in seconds, then retrieve context through summaries, categories, and search.

Download for Windows → macOS — soon.

What it does

A small set of things, done well — built around the way you actually take notes during the day.

Day notes
Append-only, timestamped capture — for meeting notes, ideas, and quick tasks.
Second brain
Daily summaries, categories, and extracted entries — grouped by day so context stays put.
Search
One search box across raw notes and second-brain entries.
Export
JSON and Markdown, anytime. Your notes leave with you.
Themes
Light and dark, both first-class.
Local-first
SQLite on your machine. No cloud sync by default.
